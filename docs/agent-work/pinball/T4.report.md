  forbids a member with the same name as a signal, so the signal is `tilted_changed()`. It
  carries no arguments and fires exactly when the tilt triggers — the table/HUD wiring matches
  the intended contract.
- `emerald` bonus `bonus_points` is 25 000 × bet (3+) / 100 000 × bet (4+), matching the spec
  table's "25 000 × bet points"; it is added directly (not × playfield_mult).
- `playfield_mult_changed` still fires on every x2/FS transition and the table plays
  `mode_start` + a "PLAYFIELD xN" message for each change (existing T3 behaviour extended).

  it is the same impulse, and it avoids the deferred-impulse cancellation by the ball's own
  `_physics_process` clamp. The old stuck-ball nudge was changed the same way.
