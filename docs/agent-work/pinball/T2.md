## Goal
1. Playfield features wired to the existing Rules events:
   LAYOUT (fixed, see T1.review-1.md for the table geometry already built):
   - INDY drop-target bank (4 targets 18×40 px, standing along the divider at x≈610,
     y 480..690, facing left into the field):
     static bodies that drop (disable collision + hide/darken) when hit → `target` {index};
     raise on `targets_reset`; handle `request_spot_target` later (T3) via method
     `spot_next_target() -> void` on the bank (drops the first standing target and fires its event).
   - Idol scoop at (360,300), in front of the idol painted on playfield.jpg (no idol sprite on
     top; add a PointLight2D glow + a dark hole Polygon2D): short U-shaped wall cup opening
     downward so the ball can enter from below; Area2D captures ball (stop it, hold 1.0 s, glow),
     fires `scoop`, then kicks it out downward-left at ≈900 px/s with a small random angle.
     Multiball: on `request_multiball(n)` spawn n balls from the scoop, one every 0.4 s,
     each firing `ball_added`.
   - 3 top rollover lanes at x 300/360/420, y 115..190, separated by 4 short posts/guides
     (Area2D, `lane` {index}), lit states from `lanes_changed`;
     flipper presses call `rules.flip_lanes(±1)` (lane change).
   - LEFT orbit only ("Path of Adventure"): guide wall x=95 from y 330 to 780 makes a lane
     x 20..95 (entrance at the bottom, y≈780, fed from the field; exit into the top arc).
     Sensor pair (bottom then top, within 1.5 s) fires `orbit` {side:"left"} once per pass;
     a one-way gate at the top keeps balls from entering it from the arc. No right orbit.
2. HUD: score, ball n/3, multiplier xN, locks, current mode name + timer + progress bar,
   transient messages (big centred text, fade), attract screen (title "TEMPLE OF THE IDOL",
   high score, "PRESS ENTER / TAP"), game-over screen (final score, NEW HIGH SCORE banner).
   High score load/save in `user://highscore.save` (corrupt/missing → 0), set on Rules
   before start_game.
3. Sound: `game/tools/gen_sfx.py` (stdlib only, deterministic) producing ALL SFX names listed in
   spec Part B (including slot ones, T3 will use them); run it and commit-ready WAVs in
   `game/assets/sfx/`. Autoload `Sfx` per spec (pool 16, loops, `music(track)` with
   crossfade, override folder). Hook every pinball event to a sound (flipper up, bumper with
   slight random pitch, sling, launch with pitch by charge, plunger_charge while held, drain,
   target, target_bank, lane, orbit, scoop, lock, jackpot, multiball, ball_save, game_start,
   game_over, mode_start, mode_complete). Music per spec amendment.
4. Pinball lights per spec Part B "Light" (CanvasModulate, PointLight2D on bumpers/scoop/ball,
   insert lamps for lanes/targets/LOCK/modes, table flash + camera shake on jackpot/multiball,
   GI flicker on drain, ball-save lamp). Keep ≥ 60 fps: ≤ 12 PointLight2D, no shadows.
